**Windows, portable.** Download `Chronos-…-Windows-portable.zip`, unzip it anywhere (your Documents, a USB stick), open the `Chronos` folder and double-click **Chronos.exe**. No installation, no Python needed.

- Your archive is kept in the `data` folder next to `Chronos.exe`. If you used Chronos before, the first start asks whether to copy that archive in, keep using it where it is, or start fresh — nothing is ever moved or deleted.
- Windows may show "Windows protected your PC" because the program isn't signed: click **More info → Run anyway**.
- To update: unzip the new version and copy your `data` folder into it (or unzip over the old one — `data` is never in the zip).
- Every build is checked on Windows before it's published: the test suite, and both programs' self-tests (`chronos-cli.exe selftest`).

What's new is in the [README](https://github.com/khangreat/chronos#readme).
