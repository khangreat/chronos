Chronos Archive — portable for Windows
======================================

Start:      double-click Chronos.exe
            (Windows may say "Windows protected your PC" because this program
            isn't signed: click "More info", then "Run anyway".)

Your data:  kept in the "data" folder here, next to Chronos.exe. Move or copy
            this whole folder and your archive goes with it.
            Help > Open data folder shows where it is.
            If you used Chronos before, the first start asks whether to copy
            that archive here, keep using it where it is, or start empty.
            Nothing is ever moved or deleted.

Updating:   download the new zip, unzip it, and copy your "data" folder (and
            portable.txt, if you changed it) into the new folder. Or unzip the
            new version over this one — "data" is never part of the zip.

Command line and the browser extension's helper:
            chronos-cli.exe   (e.g.  chronos-cli.exe help)

Check this copy works:
            chronos-cli.exe selftest

Privacy:    nothing leaves this computer unless you turn networking on in
            Settings.
